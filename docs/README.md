# Документация проекта Geometric Library

## Общее описание
Данный проект представляет собой небольшую библиотеку для вычисления геометрических характеристик простых фигур — круга, квадрата, треугольника и прямоугольника.  
Библиотека может быть использована в учебных целях или в качестве вспомогательного модуля для более сложных вычислений.  
Каждая функция снабжена комментариями и примером вызова.

---

## Описание функций

## Модуль `circle.py`

#### `area(r)`
Вычисляет площадь круга по заданному радиусу.  
**Формула:**  
\[
S = \pi r^2
\]

**Пример использования:**
```python
area(3)  # 28.274333882308138
```

---

#### `perimeter(r)`
Вычисляет длину окружности (периметр круга) по радиусу.  
**Формула:**  
\[
P = 2\pi r
\]

**Пример использования:**
```python
perimeter(3)  # 18.84955592153876
```

---

## ⬜ Модуль `square.py`

#### `area(a)`
Вычисляет площадь квадрата по длине стороны.  
**Формула:**  
\[
S = a^2
\]

**Пример использования:**
```python
area(4)  # 16
```

---

#### `perimeter(a)`
Вычисляет периметр квадрата по длине стороны.  
**Формула:**  
\[
P = 4a
\]

**Пример использования:**
```python
perimeter(4)  # 16
```

---

## ⬜ Модуль `rectangle.py`

#### `area(a, b)`
Вычисляет площадь прямоугольника по длине сторон.  
**Формула:**  
\[
S = a * b
\]

**Пример использования:**
```python
area(4, 8)  # 32
```

---

#### `perimeter(a, b)`
Вычисляет периметр квадрата по длине стороны.  
**Формула:**  
\[
P = 2 * (a + b)
\]

**Пример использования:**
```python
perimeter(4, 8)  # 64
```

---

## ⬜ Модуль `triangle.py`

#### `area(a, h)`
Вычисляет площадь треугольника по длине стороны и высоты.  
**Формула:**  
\[
S = a * h / 2
\]

**Пример использования:**
```python
area(4, 8)  # 16
```

---

#### `perimeter(a, b)`
Вычисляет периметр треугольника по длине сторон.  
**Формула:**  
\[
P = a + b + c
\]

**Пример использования:**
```python
perimeter(4, 6, 8)  # 18
```
